Help Guide
What is Dynamic SLAM?

It tracks camera movement through images - like GPS but using only a camera!

Quick Start (3 steps):
  1. Choose a video sequence from dropdown
  2. Click "Quick Demo" button
  3. View results below (appears in ~1 minute)
What do the settings mean?
Feature Type
How to find trackable points. ORB = fastest.
Max Features
More = better quality but slower. 3000 is good.
Detection Confidence
How strictly to filter moving objects. 0.30 works well.
Understanding Results:
  • Trajectory: Path camera took (bird's eye view)
  • Matches: How points are tracked between images
  • Errors: Accuracy vs ground truth
Tips:
  • Use default settings for best results
  • Try Quick Demo first (1 minute)
  • Full sequence takes 5-20 minutes
